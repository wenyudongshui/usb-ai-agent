# USB AI Agent — 使用说明与使用者须知 (README.txt)

## 这是什么
一个随身携带的私有化 AI 智能体。网页是**管理控制台**（管引擎、管提供商、管提示词档案），
真正的 AI 对话在 **Claude Code 命令行**里进行。所有配置/密钥/提示词随 U 盘携带，本机零残留。

## 首次使用
1. 双击 `start.bat`（mac/Linux 运行 `./start.sh`）；首次会自动下载便携 Node（约 30MB，需联网一次）；
2. 浏览器打开管理控制台，设置初始密码（至少 8 位，含大小写字母和数字）；
3. 网页点「**安装 / 更新引擎**」，下载官方 Claude Code（约 300MB）到 U 盘；
4. 新建**档案**：选提供商（Anthropic / DeepSeek / OpenRouter / Ollama 等）、填模型名与密钥、写提示词（systemPrompt 与 CLAUDE.md）；
5. 点档案的「激活」，再点「🚀 **命令行对话**」。

## 正常使用
1. 双击 `start.bat` → 输入密码进入管理控制台；
2. 选择/激活档案（提供商 + 提示词一键切换，等价 CC Switch 的内置实现）；
3. 点「命令行对话」，在打开的 Claude Code 终端里对话/编码；
4. 需要换工作对象时，回控制台切换档案再启动。

## 退出与清理（重要）
1. 回到网页点「**安全退出**」——程序自动清理本机残留；
2. 可选：再运行 `clean.bat`（mac/Linux：`clean.sh`）复核一次；
3. 确认后拔出 U 盘；若上次直接拔盘，下次启动会自动补清理。

## 本地离线模型（可选）
1. 运行 `tools\Setup_Local_Models.bat`（Windows）或 `./start.sh local-setup`（mac/Linux），按提示安装 Ollama 引擎与模型；
2. 在控制台新建档案，提供商选 Ollama，模型填已安装的模型名，密钥任意；
3. 启动本地 Ollama 后即可离线对话。

## 安全边界（诚实说明）
防护：控制台仅本机可访问（127.0.0.1），拦截跨站请求；需密码；本机零持久化。
不防护：专业取证/受监控电脑；第三方 API 中转对对话内容的可见性；键盘记录器；口令强度不足。
**注意**：档案的 settings.json 是 Claude Code 原生明文格式（含密钥），U 盘请妥善保管。

## 常见问题
- **忘记密码？** 数据不可恢复，删除 `data\keys\` 后重建。
- **安装引擎失败？** 检查网络/代理，网页「引擎 → 安装日志」可看进度与错误。
- **命令行对话没反应？** 确认引擎已安装且已激活档案。
- **端口被占用？** 自动从 8787 递增选空闲端口。
- **杀软拦截？** 将 U 盘程序目录加入信任/排除项。
