# USB AI Agent — 使用说明与使用者须知 (README.txt)

## 这是什么
一个随身携带的私有化 AI 智能体。你的 API 密钥、人设规则和记忆全部存放在这只 U 盘上，
本地电脑不保存任何业务数据。可接入 DeepSeek / NVIDIA / OpenRouter 等在线模型，
也可安装本地 Ollama 模型后完全离线使用。

## 首次使用
1. 双击 `start.bat`（mac/Linux 运行 `./start.sh`）；
2. 首次运行会自动下载便携 Node.js（约 30MB，需联网一次，之后缓存于 `engine\`）；
3. 浏览器自动打开登录页；设置初始密码（至少 8 位，含大小写字母和数字）；
4. 添加第一个 AI（填写模型 API 的 BaseURL / 模型名 / 密钥），可勾选「连通性测试」；
5. 选择该 AI 开始对话（流式输出）。

## 正常使用
1. 插入 U 盘，双击 `start.bat`；
2. 输入密码登录；
3. 选择 AI → 开始对话；可随时切换，各 AI 会话相互独立；
4. 右上角可「修改密码」「添加 AI」「查看本地模型」。

## 退出与清理（重要）
1. 点击界面右上角「保存并退出」或「不保存退出」——程序会自动清理本机残留；
2. 可选：再运行 U 盘根目录的 `clean.bat`（mac/Linux：`clean.sh`）复核一次；
3. 确认清理完成后再拔出 U 盘；
4. 若上次直接拔盘：下次启动会自动补清理残留，登录页会有提示。

## 本地离线模型（可选）
1. 运行 `tools\Setup_Local_Models.bat`（Windows）或 `./start.sh local-setup`（mac/Linux）；
2. 按提示选择模型（如 Gemma 4、Qwen 3.5、Ministral 3），会自动下载便携 Ollama 引擎与模型；
3. 网页端「本地模型」页点击「启动本地 Ollama」；
4. 「添加 AI」时填写：API 地址 `http://127.0.0.1:11434/v1`、模型名 `你安装的模型`、密钥 `ollama`（任意值）。
   之后断网也能对话。

## 安全边界（诚实说明）
系统防护：防止共用电脑的人翻看残留文件；U 盘丢失后无法直接读取配置与记忆（需密码）；
服务仅本机访问（127.0.0.1），并拦截外部网页跨站请求。
系统不防护：专业取证环境与受监控电脑；第三方 API 中转服务对对话内容的可见性；
键盘记录器等恶意软件在运行期间窃取已解密内容。

## 常见问题 (FAQ)
- **忘记密码怎么办？** 数据不可恢复，需重新初始化（删除 `data\keys\` 后重建）。
- **杀软拦截 start.bat？** 将 U 盘程序目录加入杀软信任/排除项。
- **首次运行下载 Node 失败？** 检查网络/代理后重新运行 start.bat；也可手动将
  Node.js（Windows x64 LTS zip）解压到 `engine\node-win32-x64\`。
- **联网失败？** 请检查网络/代理；访问海外模型需自备合规代理或中转。
- **端口被占用？** 程序会自动从 8787 开始递增选择空闲端口。
- **本地 Ollama 启动失败？** 先运行 Setup_Local_Models.bat 安装引擎；确认「本地模型」页显示引擎已安装。
