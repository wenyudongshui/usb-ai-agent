# USB AI Agent — 使用说明与使用者须知 (README.txt)

## 这是什么
一个随身携带的私有化 AI 智能体。**一个账号 → 绑定多个智能体（API 配置）+ 多套工作人格**。
网页是管理控制台，AI 对话在 **Claude Code 命令行**里进行，本机零残留。

## 整体执行流程
**前置环境检查 → 选择智能体 → 选择工作人格 → 启动命令行**
1. 双击 `start.bat`（mac/Linux `./start.sh`）；首次自动下载便携 Node（约 30MB）；
2. 登录页首次填**账号名 + 密码**（无需确认）创建并进入；之后同账号 + 密码登录；
3. **① 环境检查**：先点「检查」，确认后再点「确认安装」（约 300MB）；
4. **② 选择智能体**：手动录入，或把 **CC Switch 的 settings.json 拖入**导入；点选为当前；
5. **③ 选择工作人格**：新建（只需名称/描述/人设/CLAUDE.md），点选为当前；
6. **④ 启动**：点「命令行对话」打开 Claude Code 终端对话/编码。

## 账号（仅单账号）
- 首次填账号名 + 密码即创建（无需二次确认）；之后输入相同账号 + 密码即可进入。
- 密码加密存储、文件不可读明文。
- 不做多账号切换、账号列表管理。忘记密码：删除 `data\users\`（或整个 `data\`）后重新初始化。

## 退出
1. 用完点「安全退出」：程序清理本机痕迹并退出，**账号/智能体/工作人格数据均保留在 U 盘**；可再运行 `clean.bat` 复核。

## 本地离线模型（可选）
运行 `tools\Setup_Local_Models.bat` 安装 Ollama 引擎与模型；「选择智能体」手动添加：提供商 Ollama、模型填已装模型名、密钥任意；系统页启动本地 Ollama 后即可离线使用。

## 安全边界
防护：仅本机可访问（127.0.0.1）+ 拦截跨站；密码不可读；智能体密钥加密；零持久化。
不防护：专业取证/受监控电脑；第三方中转对对话的可见性；键盘记录器；口令强度不足。
**注意**：人格的 settings.json 为 Claude Code 原生明文格式（含密钥），U 盘妥善保管。

## 常见问题
- **命令行对话没反应？** 确认引擎已安装、已激活智能体与工作人格。
- **拖入 settings.json 无反应？** 需含 env.ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN / ANTHROPIC_MODEL 等字段。
- **忘记账号密码？** 删除 `data\users\`（或整个 `data\`）重新初始化。
