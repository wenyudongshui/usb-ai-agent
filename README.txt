# USB AI Agent — 使用说明与使用者须知 (README.txt)

## 这是什么
一个随身携带的私有化 AI 智能体。网页是**管理控制台**（管引擎、管 API 密钥、管提示词档案），
AI 对话在 **Claude Code 命令行**里进行。支持**多账号**，本机零残留。

## 首次使用
1. 双击 `start.bat`（mac/Linux `./start.sh`）；首次会自动下载便携 Node（约 30MB，需联网一次）；
2. 登录页点「＋ 新增账号」，填账号名与密码进入；
3. 「API 密钥管理」：手动填写密钥，或把 **CC Switch 导出的 settings.json 拖入**自动导入；点「设为当前」；
4. 「档案管理」：新建档案（只需名称/描述/人设/CLAUDE.md），点「激活」；
5. 「引擎」：先「① 检查」，确认后再「② 确认安装」（约 300MB，日志可见进度）；
6. 点「🚀 命令行对话」，在 Claude Code 终端里对话/编码。

## 多账号
- 退出登录后回到登录页，左侧显示**多个账号选择框**，点选后输入密码登录；
- 无历史账号时，左侧只有「＋ 新增账号」；
- 密码以加密方式存储，文件内**不可读取明文**；仅在控制台「账号管理」页可**删除**账号。

## 退出（仅两项）
1. **全部删除退出**：清除本机残留 + 全部账号/档案/密钥数据后退出；
2. **保留本次在本机的全部更改，其余数据全部清除**：不清本机，清其余全部数据后退出。

## 本地离线模型（可选）
1. 运行 `tools\Setup_Local_Models.bat`（Windows）或 `./start.sh local-setup`，按提示安装 Ollama 引擎与模型；
2. 「API 密钥管理」手动添加：提供商选 Ollama，模型填已安装模型名，密钥任意，设为当前；
3. 控制台「系统」页启动本地 Ollama 后即可离线对话。

## 安全边界（诚实说明）
防护：控制台仅本机可访问（127.0.0.1），拦截跨站请求；多账号密码不可读；API 密钥加密存储；本机零持久化。
不防护：专业取证/受监控电脑；第三方 API 中转对对话内容的可见性；键盘记录器；口令强度不足。
**注意**：档案激活后生成的 settings.json 为 Claude Code 原生明文格式（含密钥），U 盘请妥善保管。

## 常见问题
- **忘记账号密码？** 该账号数据不可恢复；可新增新账号，或删除旧账号。
- **拖入 CC Switch settings.json 无反应？** 需含 env.ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN / ANTHROPIC_MODEL 等字段。
- **安装引擎失败？** 检查网络/代理，看「引擎 → 安装日志」。
- **端口被占用？** 自动从 8787 递增选空闲端口。
- **杀软拦截？** 将 U 盘程序目录加入信任/排除项。
