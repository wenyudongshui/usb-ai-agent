# USB AI Agent — 使用说明与使用者须知 (README.txt)

## 这是什么
一个随身携带的私有化 AI 智能体。你的 API 密钥、人设规则和记忆全部存放在这只 U 盘上，
本地电脑不保存任何业务数据。

## 首次使用
1. 将便携 Node.js（Windows x64 免安装 LTS 版）解压到 `node\` 目录；
2. 双击 `start.bat`，浏览器会自动打开登录页；
3. 设置初始密码（至少 8 位，含大小写字母和数字）；
4. 添加第一个 AI（填写模型 API 的 BaseURL / 模型名 / 密钥），完成连通性测试；
5. 选择该 AI 开始对话。

## 正常使用
1. 插入 U 盘，双击 `start.bat`；
2. 输入密码登录；
3. 选择 AI → 开始对话；可随时切换，各 AI 会话相互独立。

## 退出与清理（重要）
1. （推荐）在界面点击「保存并退出」或「不保存退出」；
2. 运行 U 盘根目录的 `clean.bat`，清除本机残留；
3. 确认清理完成后再拔出 U 盘；
4. 若上次是直接拔盘：下次启动后界面会提示补清理，届时运行一次 `clean.bat` 即可。

## 安全边界（诚实说明）
系统防护：防止共用电脑的人翻看残留文件；U 盘丢失后无法直接读取配置与记忆（需密码）。
系统不防护：专业取证环境与受监控电脑；第三方 API 中转服务对对话内容的可见性；
键盘记录器等恶意软件在运行期间窃取已解密内容。

## 常见问题 (FAQ)
- **忘记密码怎么办？** 数据不可恢复，需重新初始化（删除 keys\ 后重建）。
- **杀软拦截 start.bat？** 将 U 盘程序目录加入杀软信任/排除项。
- **联网失败？** 请检查网络/代理；访问海外模型需自备合规代理或中转。
- **端口被占用？** 程序会自动从 8787 开始递增选择空闲端口。
